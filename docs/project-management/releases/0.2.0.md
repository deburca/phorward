# Release 0.2.0 (experimental)

## Highlights
- `phorward verify` scopes syntax and phpcs to the changed files (`gates.scope`), widening to the whole project when a phpcs ruleset changed
- `phpcbf` check returns a patch; `phorward verify --fix` (or `gates.fix`) applies it after validating every line
- Bounded, git-aware archive (`sync.max_size`, `sync.respect_gitignore`)
- `harness:install` and generic harness templates; `harness.command` setting

## Schema / migration notes
- Protocol stays at version 1; the changes are additive (`--paths`, `phpcbf`, `patch` fields, `info.features`). A new client against an old server falls back to whole-project runs without auto-fix; an old client against a new server is unaffected.
- Server kit: update `phorward-run` and rebuild `php-library` images (its `phorward-check` gained a `phpcbf` mode). `drupal-module` images need no rebuild.
